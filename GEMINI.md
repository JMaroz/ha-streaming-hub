# Streaming Hub Guidelines & Language Policy

## Language & Communication Policy
- **Chat Conversations**: Always interact with the user in **Italian** (`it-IT`).
- **Codebase & Implementation**: Strictly **English** (`en-US`) for all:
  - Source code (Python, JavaScript, HTML, CSS)
  - Identifiers, functions, classes, variables, constants
  - Docstrings, inline comments, code documentation
  - Log messages and internal error details
- **Git & Version Control**: Strictly **English** (`en-US`):
  - Git commit messages (following Conventional Commits, e.g. `feat(cast): ...`, `fix(api): ...`, `chore(ui): ...`)
  - Git tags and annotations
  - Branch names
- **Releases & Documentation**: Strictly **English** (`en-US`):
  - GitHub release titles and release notes (`gh release create`)
  - `CHANGELOG.md` entries
  - Project documentation and README files
